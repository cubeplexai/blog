# CubePlex 微信文章样式

CubePlex 文章默认使用与官网博客以及既有公众号文章一致的克制编辑风格。正文不堆叠卡片或装饰，用品牌蓝色标题、自然段落和充分留白建立层级，并兼顾微信的浅色与深色阅读模式。

## 设计 token

- 主标题与章节标题：`#0a0a0b`
- 正文：`#1f1f22`
- 次要文字：`#52525b`
- 弱化文字：`#71717a`
- 边框：`#e4e4e7`
- 浅背景：`#f4f4f5`
- 品牌强调色：`#5b7cfa`
- 深色背景：`#0a0a0b`

## 排版规则

- 微信后台单独显示文章标题，正文 HTML 不重复输出 H1。
- 正文统一使用 17px、1.85 行高；第一段不设置导语专属字号或灰色样式。
- H2 使用 23px、粗体、品牌蓝色和底部细分隔线。长标题左对齐，避免手机端居中断行。
- 正文段间距 18px，章节上方留白 42px。
- 图片宽度 100%，使用 1px 灰色边框和 8px 圆角；图片说明为 13px 灰色居中正文。
- 公众号正文不输出普通外链。Markdown 链接只保留可读标题，不生成 `<a>`。
- 不凭空增加金句、摘要框、结论卡片或正文中不存在的文字。
- 不输出文章末尾的“参考资料”和“阅读博客原文”。
- 页尾沿用既有公众号文章的“关于 / CubePi / CubePlex”结构，GitHub 地址以普通文本显示。

## 内容保真

公众号稿必须直接从当前文章源文件生成。转换只处理 front matter、Markdown/MDX 标记、图片路径和排版，不得改写、概括、删减或重新排列正文。需要编辑内容时，应先修改文章源文件，再重新生成微信稿。
