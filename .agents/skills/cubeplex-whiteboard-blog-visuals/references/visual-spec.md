# CubePlex Workspace Whiteboard Visual Specification

Derived from representative frames of `CubePlex_AI_Workspace.mp4` on 2026-08-28. Treat this as a visual direction, not as a source of product claims.

## Visual vocabulary

| Element | Direction |
| --- | --- |
| Canvas | Warm white, with a very faint square grid. A sparse pale-blue arch, node graph, or diagram may sit beneath the foreground. |
| Drawing | Black or charcoal ink outlines with slight irregularity. Rounded corners. Small areas receive diagonal scribble or pencil shading. |
| Main structure | Large rounded product card, centered object, or evenly spaced step cards. Use a thin blue connector for an ordered flow. |
| Color hierarchy | Off-white ground; near-black ink; light powder-blue panels and construction shapes; saturated signal blue for the active product object; bright but restrained yellow highlighter. |
| Supporting icons | Simple, friendly, hand-drawn technical and office objects. They are explanatory annotations rather than decorative clip art. |
| Typography | High-contrast black sans-serif for headings, with selected words behind loose yellow highlighter blocks. Add typography outside generated raster art. |

## Guardrails

- Avoid dark backgrounds, neon glows, glassmorphism, gradients, isometric scenes, stock photography, and dense product UI mockups.
- Avoid a generic children’s cartoon treatment. Keep the marks hand-drawn but the layout disciplined and businesslike.
- Avoid more than two yellow emphasis marks in an image and avoid using yellow for large containers.
- Avoid drawing logos, long labels, code samples, or Chinese/English text with an image model. Composite exact text afterward.
- Preserve enough blank space for article copy. The visual should breathe at mobile width as well as desktop width.
